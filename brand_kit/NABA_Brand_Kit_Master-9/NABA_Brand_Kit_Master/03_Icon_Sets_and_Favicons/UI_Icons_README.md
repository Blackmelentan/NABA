# NABA UI System Icons

All icons follow the dual-tone language of the locked logo:
- Primary stroke: #111111 (matching lion line weight)
- Accent fill / highlight: #F5A623
- ViewBox: 0 0 24 24
- Stroke-width: 1.5–2 (consistent with logo)

SVG files below are production-ready and can be used directly in web/app.
